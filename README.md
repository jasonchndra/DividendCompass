# Dividend Compass V1.0
Dividend Compass is a minimalist financial planning utility engineered to bridge a critical functional gap in traditional brokerage applications like Stockbit, which inherently lack native, lifestyle-driven dividend analysis modules. Developed as a high-speed, serverless proof-of-concept using Python and AI-augmented development via Cursor, the platform features a bidirectional, multi-tab execution engine that automates IDX ticker sanitization and applies Indonesia’s 10% final dividend tax rule. It enables retail investors to seamlessly toggle between a Lifestyle Calculator (mapping portfolio yields against real-world costs like specialty coffee or gym memberships) and a Reverse Goal Planner (reverse-engineering targeted passive income milestones into precise lot acquisition and capital requirements), demonstrating advanced proficiency in modular codebase design, isolated state management, and user-centric financial literacy products.
